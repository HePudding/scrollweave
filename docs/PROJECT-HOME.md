# 项目管理主页 · 2026-09-20

ScrollWeave 的默认入口现在是 `/` 项目主页；`/editor` 是剪辑工作区。主页与原有编辑器、MCP 共用同一个本地服务和当前项目。

## 参考与实现

查看了 DeepSeek 官方 [Harness 仓库](https://github.com/deepseek-ai/deepseek-harness)、[Web UI 使用文档](https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart)、[工作区组件说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-workspace/README.md)、`AppFrame.tsx` 和 [网页目录浏览器](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-directory-picker-browse/src/client/DirectoryBrowser.tsx)。参考其侧边导航、持久化工作区登记、显式目录选择，以及移除登记时保留磁盘文件的方式。

ScrollWeave 的首页按创作项目重新设计：左侧为项目导航与最近打开，右侧为新建/打开入口、项目卡片和搜索。保留原有深色与浅绿色视觉。实现沿用现有 React、Express、项目命令与文件校验；未引入 Harness 运行时，也未复制其源码、商标或资源。

## 操作

- **新建项目**：输入名称，在选择的父目录中创建独立作品文件夹。默认 1920×1080 空时间线。重名目录会报错，不覆盖已有目录。
- **打开已有项目**：直接调用操作系统的文件夹选择器，选定后校验并打开项目。取消不会切换作品。新建项目的“更改保存位置”也使用系统选择器，取消后保留名称和原保存位置。
- **最近项目与收藏**：登记、收藏、打开时间保存在用户目录 `.scrollweave/projects.json`，重启保留。通过 MCP 新建/切换的项目也登记。
- **搜索和视图**：按名称/路径搜索，按最近打开、项目文件修改时间或名称排序；支持收藏筛选与网格/列表切换。Ctrl/Command+K 定位搜索框。视图偏好保存在当前浏览器。
- **重命名**：更新项目文件内的名称，保留目录名；检查 revision，活动项目复用原有事务与撤销，其他项目取得进程锁后原子写入。
- **移出列表**：只隐藏登记，保留完整作品与素材，可用打开文件夹重新加入。服务启动不会恢复已隐藏登记。
- **失效目录**：项目移动、磁盘离线或项目 JSON 损坏时保留卡片并显示状态，不自动删除登记。
- **返回剪辑**：打开项目进入 `/editor`；左上返回项目主页。浏览器前进/后退和直接刷新地址均可使用。首页不会播放作品或改变播放头。

## 数据与边界

`SW_PROJECTS_DIR` 指定默认新项目父目录；`SW_LIBRARY_PATH` 指定列表文件，测试使用独立临时目录。列表通过临时文件与原子重命名持久化，写入使用短期进程锁；损坏的列表文件不会被静默覆盖。列表只读取已登记作品，不递归发现整个磁盘。

卡片使用缓存中的图片/视频缩略图或清理后的 SVG，尚无缓存时显示文字封面。封面不是时间线某帧的完整截图。最近修改按项目文件 mtime 排序，包括自动保存的会话信息。

网页目录树及其 500 个子目录限制已移除。`POST /api/directories/pick` 由本地服务打开系统选择器，返回真实目录或取消结果。Windows 使用 PowerShell 宿主调用 WinForms `FolderBrowserDialog`，优先 PowerShell 7 的现代系统对话框；未安装时使用系统自带的 Windows PowerShell。目录通过环境变量传入，不拼接为脚本。Linux 优先使用桌面对应的 Zenity/KDialog，缺少一个时尝试另一个。没有桌面会话、缺少选择器或启动失败时，页面提供完整路径输入和重试入口。macOS 暂使用路径输入。

浏览器的 [showDirectoryPicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker) 返回目录句柄，不暴露供 Node 服务监听的绝对路径，因此这里由本地服务打开系统对话框；选择器显示在服务所在电脑上。服务只允许一个选择窗口；网页取消、关闭或刷新会中止该请求并结束窗口进程。Windows 选择器进程不使用 `SW_HIDE`，避免连带隐藏交互对话框。

同一服务仍维护一个活动作品，其他编辑器页面和 MCP 会同步切换。首页不是同时运行多个独立剪辑会话的调度器。编辑器仍主要面向桌面，原有媒体和导出支持边界不变。
