## 实测边界

最初桌面被用户操作打断，多次收到 `user input was detected` 和非目标窗口错误。用户说明不再操作后重新获取窗口并完成以上实验。素材卡片拖入、片段整体水平/跨轨拖动多次调用未可靠提交（右侧裁边成功）；因此**不将拖动落位、插入/覆盖冲突、左裁边、吸附阈值、轨道联动的完整规则标记为已验证**。未实测复合片段复制后的共享/独立语义、所有快捷键及曲线编辑器。不推断本机不存在这些功能。

## ScrollWeave 本轮设计决策（不是剪映实测结论）

- 默认先入素材库，5 秒静态片段、视频真实时长；素材预览与作品播放头独立。
- 默认自由编排，普通删除留空；插入、覆盖、波纹删除各有明确操作。吸附仅对齐，不代表后续内容联动。
- 同轨重叠必须显式选择插入或覆盖，跨轨用于叠加；普通移动不会隐式推动其他片段。
- 秒是稳定编排单位，片段保存源取用位置和独立关键帧；裁剪不重定时，分割不重置源进度。
- 复合片段共享内容可复用，并提供创建独立副本；进入共享内容时显示影响范围。
- 文件监听属于素材系统，编辑撤销只撤销作品编排，不回写 Agent 修改的源文件。

这些规则以本地操作证据为参考；未可靠完成的剪映操作不作为一致性保证。新版验收会独立验证 ScrollWeave 的实际行为。
