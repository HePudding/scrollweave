## 真实支持范围与限制

- 已实际解码和浏览器播放：MP4 / H.264 / yuv420p / AAC；WebM / VP9 / Opus。VP8/Vorbis可通过格式门禁，但本次没有单独做浏览器编码组合验收。MPEG-4 Part 2放入MP4明确报错。没有“支持所有视频”的承诺。
- 单素材上限512MB，SVG源上限10MB；媒体探测/缩略帧子进程30秒超时。没有代理视频、后台转码队列或自动降码率，大分辨率/长GOP素材的加载和反向seek可能慢。
- 自动化验证音频解码、未静音和音量状态，没有做扬声器听觉测试。滚动默认静音；没有音频专轨、复杂混音、倒放声音、转场库或完整视频编码导出。
- SVG以矢量img呈现；出于确定性与资源边界，脚本、事件、外链、foreignObject、嵌入image、CSS样式和SVG内置动画被清理，复杂SVG可能改变外观，库中明确提示。建议Agent使用路径、形状、渐变及呈现属性。
- 新建静态片段默认5秒；视频1倍速按源时长。项目最小初始10秒，增加内容自动延长，删除后不自动缩短；可在作品信息中调时长，但不能短于内容。
- 多选画布变换暂不支持，明确禁用；多选移动、复制、删除、分割、复合有效。旧版group保留，可从画布或折叠结构列表选择内部节点；不提供有损的一键解组。
- 缺失/损坏且被引用的素材会阻止完整交付。错误SVG可继续显示最近有效缓存，但要修复后才能交付。重新关联到更短视频会保留剪辑并给出警告，超出部分保持末帧。
- Undo最多80次，仅当前进程；外部文件与导入动作不撤回磁盘字节。缓存保存历史版本，尚无自动垃圾回收。
- 主要验收桌面Chrome，编辑器最小1080px。导出整体等比适配或居中裁切，不做移动端文字自动重排；系统字体跨机器可能变化。flow区间按自然文档流经过，距离也形成页面留白。
- 不含云发布、账号、付费资源、私有素材抓取。本轮未改已有剪映私人草稿；测试草稿与生成素材留作复核。
