# 首版验收与已知限制

验收环境：Windows，本机 Node.js 26.5.0、npm 12.0.2、已安装的 Google Chrome，通过 Playwright headless 运行。测试不使用模型 API 或云服务。项目范围是可运行的 0.1 首版，不是完整 AE。

本机交互改进验收（2026-09-17）：**30/30 核心与持久化测试、15/15 浏览器测试通过**；类型检查与生产构建通过。首版依赖许可证扫描与 `npm audit --omit=dev` 已通过（0 vulnerabilities），本次未增加依赖。生产服务已另外实际启动检查。GitHub Actions 配置已提供，尚未在远程 CI 执行。

## 自动化验证

执行命令：

```sh
npm run typecheck
npm test
npm run test:e2e
npm run licenses
npm run build
```

核心与持久化测试覆盖：

- 任意进度正向、反向和随机采样的确定性；首尾与嵌套区间边界。
- 多实例的独立局部进度、直接/间接循环拒绝、嵌套组的区间映射。
- 原子批次的一次撤销与重做；失败批次、磁盘错误回滚；revision 冲突不覆盖。
- 部分属性修改不会补默认值并破坏其他属性。
- 保存/JSON 恢复、导入子项目的 ID 与素材引用重映射。
- 分组复制、删除、静态解组；关键帧更新、重复帧位置与透明度范围校验。
- 重复应用预制到现有轨道；贝塞尔插值；脚本标签转义与资源内嵌。
- **启动真实服务 → 修改 → 保存 → 停止进程 → 重新启动 → 验证项目/revision/选择/预览恢复**；另一个进程无法占有同工作区。

15 个浏览器用例覆盖：

1. 人工修改关键帧 → 官方 MCP Client 通过 HTTP 修改同项目 → SSE 立即反映 → UI 一次撤销 → 保存项目下载 → 新建 → 重开下载文件 → UI 导出 → file:// 独立打开 → MCP 返回真实 PNG。
2. 预览与离线 HTML 在 0%、12%、43%、68%、96%、100% 及反向、快速跳转序列中比较所有元素变换/透明度/可见性，**同时比较 PNG 逐像素相等**。验证中段 sticky、横向位移、退出 sticky 后 CTA 可见、PageUp 有效。
3. 平滑模式目标突变时暂时落后，从实际显示状态反向追赶，并收敛。
4. 同一子合成多实例的 DOM/进度独立，循环引用失败不更新 revision，导入仍可嵌套。
5. 真正的鼠标拖动、尺寸手柄、旋转手柄、关键帧数值与贝塞尔控制点修改写入项目。
6. 上传真实 PNG、内嵌保存、裁切后独立 HTML 显示正确图像。
7. 真正的 stdio MCP 子进程桥接，读同一 revision，错误参数返回真实错误。
8. 原生预览滚动 → MCP 可读播放头；MCP 定位 → 已打开的原生预览同步。
9. vis-timeline 中直接拖动关键帧与区间边缘，验证服务器项目变化。
10. 人类正在编辑文字时 Agent 提交，失焦提交显示版本冲突；隐藏父组后子元素不可见。
11. 真实滚轮默认纵向滚动且不缩放；Ctrl+滚轮缩放、Shift+滚轮横移、Shift+Z 恢复完整区间。
12. 精简轨道收起全程静态素材与无关属性，标题色块长度与淡出边界一致；新增文字只占 20%，出点后隐藏。
13. Q/W 与底栏裁边、Ctrl+B 分割、Ctrl+Z 撤销；原曲线不变，切点只显示一段，输入文字不触发裁剪。
14. 多选关键帧真实拖动作为一次操作撤销、Ctrl+C/V 粘贴、方向键微调、Delete 不删图层、Alt+方向键跳转与 Space 播放暂停。
15. 真实 MCP 同批分割分组和嵌套合成 → 保存重开 → file:// 离线导出，在切点前后及反向跳转序列与未分割原页面逐像素比较。

新增核心用例同时验证裁剪不改变随机采样曲线、半开切点、组后代复制、素材平移、延长静态时长、关键帧整批碰撞检查、v1 旧文件默认值、失败与冲突回滚。

截图与下载文件由 Playwright 保存在 test-results/；该目录不入版本控制。完整测试代码是验收证据，单张截图不能代替这些行为测试。

## 已实现边界

本地项目、中文界面、素材/图层/画布/属性/多轨时间线、关键帧与曲线、撤销、嵌套、原生滚动、两种追随方式、真实 MCP、可分享项目包和独立 HTML 已落地。示例包含标题和产品进入、产品改变构图、中段固定横向卡片、纵向收尾与可点击行动按钮。自带预制使用公开扩展接口。

## 未实现

- 不包含账号、云端同步、多人协同或内置 AI 聊天。多人同时操作是版本冲突检测，不是自动合并；选择与预览是共享会话状态。
- 不包含视频/音频/动画图片、任意网页反向导入、SVG 编辑、路径蒙版、骨骼、3D、完整 AE 特效或交互状态机。
- 不包含移动端重排与完整布局约束求解；layout 字段为未来预留，目前执行固定坐标和整体 contain/cover。
- 不包含 Astro/其他工程导出与插件市场；源码扩展入口已提供，UI/MCP 当前只开放 HTML 导出。
- 不支持将有旋转、缩放或关键帧的组无损烘焙解组；会明确报错并保留项目。可继续把组当作一个整体编辑。
- 多选用于分组和批量删除/复制；画布手柄编辑首个选择项。需要同时变换时请先分组。
- 时间线支持关键帧多选拖动/复制/删除与批量缓动；多选时属性数值和位置只修改第一帧，面板有说明。没有框选、波纹剪辑或快捷键自定义面板。
- 撤销栈只在当前服务中保留最近 80 次，重启不会恢复历史。保存包保留可编辑状态，不保留操作日志。

## 尚未全面验证与容量限制

- Firefox、Safari、移动浏览器、触摸交互、不同操作系统字体和高 DPI 渲染尚未全面验收。交付环境是桌面 Chromium；系统字体可能导致跨平台细微排版差异。
- 未做长时间耐久运行、数千图层、大图片项目和多 Agent 压力测试。schema 有层数/合成数/展开数限制；请求上限 60MB、UI 单图上限 10MB。
- 自定义元素代码属于受信任源码，首版没有脚本沙箱，也没有专属属性面板自动生成器。
- flow 区间比视口更短时没有足够的滚动距离播放复杂动画；建议 flow 用静态内容，复杂滚动动画放到 pin 区间。
- 开发模式修改服务端/运行时代码后应重启服务；生产分发请重新构建。应用内项目编辑与关键帧修改无需重启。

整个核心流程不依赖第三方在线资源。MCP 截图首次需要可用 Chromium；没有浏览器时会明确报错，不返回模拟成功。
